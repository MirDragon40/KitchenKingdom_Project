# Kitchen Kingdom

Unity / Photon PUN 2 기반 4인 멀티플레이 협동 요리 게임
(오버쿡드 2 모작)

## 프로젝트 개요

- 개발 유형: MBC HRD 개발자 양성과정 팀 프로젝트
- 개발 기간: 2024.05 ~ 2024.06
- 개발 인원: 4명
- 기술 스택: Unity, C#, Photon PUN 2
- 플레이 영상: [YouTube](https://youtu.be/-ivMEoBC46g)

플레이어들이 협동하여 제한 시간 안에 재료를 손질하고
요리를 완성하는 멀티플레이 게임입니다.
스테이지별 획득 점수에 따라 평점과 엔딩이 달라집니다.

## 팀 구성

| 팀원 | 주요 담당 |
| --- | --- |
| 김성준 | Photon 연결, 로비, 방, 주문 및 음식 조합, 오브젝트 소유권 이전, 스테이지 매니저 |
| 민예진 | 레벨 디자인, 스토리 씬, 로딩 및 영수증 UI, 콜라 |
| 전민성 | 화재 및 소화, 스토브, 팬, 테이블, 사운드 |
| 정수빈 | 설거지, 재료 손질, 조리대 공통 구조, 결과 및 엔딩, 씬 관리, 스테이지 구성 |
